단순 감쇠 조화 운동 증명

1. 감쇠 조화 운동이란?

감쇠 조화 운동은 진동하면서 시간이 지날수록 진폭이 점점 감소하는 운동이다.

공기 저항이나 마찰 때문에 에너지가 줄어들어 결국 운동이 멈추게 된다.

2. 작용하는 힘

물체에는 두 가지 힘이 작용한다.

1. 원래 위치로 돌아가게 하는 용수철 힘

F = -kx

2. 움직임을 방해하는 마찰력

F = -bv

속도가 빠를수록 마찰력이 커진다.

3. 뉴턴의 운동 법칙 적용

뉴턴의 운동 법칙:

F = ma

전체 힘을 모두 합하면:

m d²x/dt² = -b dx/dt - kx

모든 항을 왼쪽으로 이동하면:

m d²x/dt² + b dx/dt + kx = 0

이 식이 감쇠 조화 운동의 기본 미분방정식이다.

4. 지수함수 형태 가정

미분해도 형태가 유지되는 지수함수를 이용한다.

x = Aert

미분하면:

dx/dt = Arert
d²x/dt² = Ar²ert

5. 이차방정식으로 변환

원래 식에 대입하면:

mAr²ert + bArert + kAert = 0

ert 는 0이 될 수 없으므로:

mr² + br + k = 0

즉, 2차 미분방정식이 이차방정식으로 바뀐다.

6. 왜 b²-4mk 가 음수인가?

특성방정식:

mr²+br+k=0

근의 공식:

r=(-b±√(b²-4mk))/2m

여기서 판별식:

b²-4mk

의 부호에 따라 운동 형태가 달라진다.

감쇠 조화 운동은 “진동하면서” 감소하는 운동이어야 한다.

만약:

b²-4mk > 0

이면 근은 서로 다른 두 실수가 된다.

r₁,r₂ ∈ 실수

그러면 해:

x(t)=Aer₁t+Ber₂t

는 단순히 증가하거나 감소할 뿐, 사인·코사인 형태의 반복 진동이 나타나지 않는다.

즉, 진동 운동이 아니라 그냥 천천히 원위치로 돌아가는 운동이 된다.

반대로:

b²-4mk<0

이면 음수의 제곱근 때문에 복소수가 등장한다.

r=α±iω

오일러 공식:

eiθ=cosθ+isinθ

을 사용하면 사인·코사인 진동이 나타난다.

x(t)=Ae-bt/2mcos(ωt+φ)

즉, 진동이 존재하려면 복소근이 필요하고, 복소근이 존재하려면 판별식이 음수여야 한다.

따라서 감쇠 조화 운동에서는:

b²-4mk<0

이어야 한다.

7. 복소수의 등장

판별식이 음수가 되면:

b² - 4mk < 0

복소근이 등장한다.

r = α ± iω

오일러 공식을 이용하면:

eiθ = cosθ + isinθ

복소수가 사인·코사인 진동으로 연결된다.

8. 최종 결과

x(t)=Ae-bt/2mcos(ωt+φ)

시간이 지날수록 진폭이 감소하면서 계속 진동하는 운동이 나타난다.

이를 통해 복소수가 실제 자연의 진동 운동을 설명하는 데 사용된다는 것을 알 수 있다.
